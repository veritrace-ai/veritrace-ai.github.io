Under the hood

Why a VeriTrace code is hard to fake.

Not every QR code is a security feature. A printed QR that simply points at a website can be copied by anyone with a camera and a printer. VeriTrace codes are signed.

01

Cryptographically signed

Each identifier is generated with a signing key held in your tenant. The registry can prove a code is yours — and a counterfeiter cannot mint a new valid one, even if they copy the label artwork perfectly.

02

Impossible paths are flagged

A unit cannot be legitimately in two cities at once. When scan geography contradicts the recorded journey, the code and its batch are flagged for investigation automatically.

03

First-scan detection

Genuine new stock is usually scanned for the first time by the person who buys it. A code that was already scanned elsewhere raises a visible caution rather than a false all-clear.
